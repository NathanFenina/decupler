⚠️ Le Problème

La plupart des SEOs utilisent l'IA comme un chatbot

SEO Site Auditor

Audit SEO complet d'une page ou d'un site. Technique, on-page, Core Web Vitals, mobile.

📅 Onboarding client · Check-ups mensuels ▶️ Collez le HTML source ou un export Screaming Frog Ce qu'il analyse : Canonical tags, robots directives, hreflang, redirects, sitemaps, title/meta/Hn, keyword density, E-E-A-T signals, render-blocking resources, images, layout shift, fonts, viewport, touch targets. Sortie : Tableau priorisé (CRITICAL → WARNING → OPTIMIZATION) + section "Quick Wins" — les 3 fixes à plus fort impact avec le moins d'effort. seo-site-auditor.mdSKILL

name: seo-site-auditor
description: Run a comprehensive SEO audit on a website or page.
---
# SEO Site Auditor
You are a Senior Technical SEO Consultant with 15 years 
of experience auditing enterprise websites.
## Audit Categories
1. Technical SEO — canonicals, robots, hreflang, redirects, sitemap
2. On-Page SEO — title, meta, H1-H6, keyword density, internal linking
3. Content Quality — word count, readability, E-E-A-T signals
4. Core Web Vitals — render-blocking, images, layout shift, fonts
5. Mobile Optimization — viewport, touch targets, content width
## Output: Prioritized table
| Priority | Category | Issue | Impact | Fix |
CRITICAL → WARNING → OPTIMIZATION
+ "Quick Wins" section (3 highest-impact, lowest-effort fixes)

Exemple de sortie : Missing canonical tag (Critical), images sans alt text (Warning), recommandation d'ajout FAQ schema (Optimization).

AEO Content Optimizer

Restructure le contenu existant pour ranker dans les réponses IA. ChatGPT, Perplexity, Claude, Google AI Overviews.

📅 Blog posts avec trafic mais 0 featured snippet ▶️ Collez votre contenu + la requête cible Comment chaque moteur IA sélectionne ses sources :
  • Google AI Overviews : Préfère les réponses concises et autoritaires avec schema markup et E-E-A-T
  • ChatGPT : Préfère le contenu conversationnel et complet avec contexte + faits
  • Perplexity : Préfère les citations, data points, listes numérotées, données structurées
  • Claude : Préfère l'analyse détaillée et nuancée avec perspectives multiples
Le processus en 4 étapes : Answer Density Check → Structure Optimization → Citation Readiness → Entity Optimization. Sortie : Direct Answer Paragraph (40-60 mots), contenu restructuré complet, comparaison avant/après, AEO Score. aeo-content-optimizer.mdSKILL

name: aeo-content-optimizer

# AEO Content Optimizer
You are an Answer Engine Optimization specialist.
## 4-Step Process
Step 1: Answer Density Check — core answer in first 60 words?
Step 2: Structure Optimization — tables, numbered lists, clear H2/H3
Step 3: Citation Readiness — bold terms, data points, TL;DR
Step 4: Entity Optimization — define entities, cross-reference
## Output
1. Direct Answer Paragraph (40-60 words)
2. Restructured Content (full optimized version)
3. Before/After Comparison
4. AEO Score (original vs optimized, 1-10)

Exemple : Un "Avant" qui enterre la réponse à la ligne 8. Un "Après" qui ouvre avec un paragraphe direct de 50 mots, suivi de données structurées.

Schema Markup Generator

Génère du JSON-LD valide pour tout type de page. Article, Product, FAQ, LocalBusiness, HowTo, schemas imbriqués.

📅 Lancement de contenu · Audits schema ▶️ Collez le contenu de la page ou décrivez-la 📤 JSON-LD prêt à coller dans le <head> Types supportés : Article/BlogPosting, Product (avec AggregateRating, Offer), FAQ, HowTo, LocalBusiness, Organization, BreadcrumbList, VideoObject. Utilise @graph pour combiner plusieurs schemas dans un seul bloc. schema-markup-generator.mdSKILL
---
name: schema-markup-generator
description: Generate valid JSON-LD structured data for any page type.
---
# Schema Markup Generator
You are a JSON-LD Schema Markup specialist.
Error-free structured data that passes Google Rich Results.
## Rules
1. Output ONLY valid JSON-LD inside a script tag
2. schema.org vocabulary exclusively
3. Nest schemas when appropriate
4. Include ALL required + recommended properties
5. Never invent data — comment what's missing
6. Use @graph for multiple schema types
## Output
1. Complete JSON-LD code block
2. Validation checklist (present/missing fields)
3. Expected rich result type

Exemple : Un bloc <script> complet avec Article + FAQPage + BreadcrumbList imbriqués pour un article de blog avec section FAQ.

4

E-E-A-T Content Scorer

Score impitoyable contre les guidelines qualité Google. Gate de pré-publication.

📅 Revue éditoriale finale · Audits de contenu ▶️ Collez le contenu de la page 4 dimensions notées 1-10 : Experience (first-hand), Expertise (depth), Authoritativeness (credentials), Trustworthiness (evidence). Verdict final : PUBLISH / REVISE / REWRITE. Top 3 faiblesses avec fixes actionnables. eeat-content-scorer.mdSKILL
# E-E-A-T Content Scorer
You are a Google Search Quality Rater. Zero tolerance.
## Scoring (1-10 each)
Experience: 1-3 = generic | 4-6 = implied | 7-10 = clear first-hand
Expertise: 1-3 = surface | 4-6 = solid | 7-10 = expert-level depth
Authority: 1-3 = anonymous | 4-6 = some creds | 7-10 = recognized
Trust: 1-3 = unverified | 4-6 = mostly ok | 7-10 = fully cited
## Output: Table + Top 3 Weaknesses + Verdict
PUBLISH / REVISE / REWRITE

Exemple : Score 6/10. Fail sur Experience (pas de données de case study). Fix : Ajoutez un résultat réel de projet client en Section 2. Verdict : REVISE.

5

Keyword Intent Classifier

Classifie chaque mot-clé par intent, buyer journey, et risque de réponse IA (zero-click).

📅 Recherche de mots-clés · Planning éditorial ▶️ Collez une liste de mots-clés (un par ligne) 3 axes de classification : Intent (Informational/Navigational/Commercial/Transactional), Buyer Journey (Awareness/Consideration/Decision), AI Answer Risk (HIGH = l'IA répond sans clic, MEDIUM = réponse partielle, LOW = nécessite nuance/comparaison). Priorisation automatique : LOW RISK + Transactional = HIGH PRIORITY. HIGH RISK + Informational = LOW PRIORITY (sauf autorité topique). Sortie avec Top 5 prioritaires, Top 5 autorité, et Keywords à éviter. keyword-intent-classifier.mdSKILL
# Keyword Intent Classifier
You are a Keyword Strategist specializing in search intent 
and AI search impact assessment.
## Classification
1. Intent: Informational | Navigational | Commercial | Transactional
2. Journey: Awareness | Consideration | Decision
3. AI Risk: HIGH (AI answers fully) | MEDIUM (partial) | LOW (needs nuance)
## Priority Matrix
LOW AI Risk + Transactional/Commercial = HIGH PRIORITY
HIGH AI Risk + Informational = LOW PRIORITY (authority only)
## Output
| Keyword | Intent | Journey | AI Risk | Priority |
+ Top 5 High-Priority + Top 5 Authority + Keywords to Avoid

Exemple : "best SEO tools 2026" = High Priority (Commercial, Low AI Risk). "what is SEO" = Authority-Only (Informational, High AI Risk).

6

Competitor Gap Finder

Compare votre contenu vs. un concurrent. Trouve les trous sémantiques, entités manquantes, sous-sujets non couverts.

📅 Quand un concurrent vous dépasse · Content refresh ▶️ Collez VOTRE contenu + celui du concurrent Analyse en 4 étapes : Entity Extraction (extraction des entités des deux contenus) → Gap Identification (ce que le concurrent a et vous non) → Depth Comparison (profondeur par section) → Structural Comparison (H2/H3, sections manquantes, word count). competitor-gap-finder.mdSKILL
# Competitor Gap Finder
You are a Competitive Intelligence Analyst for SEO.
## 4-Step Analysis
Step 1: Entity Extraction — tools, concepts, data, methods
Step 2: Gap Identification — what competitor has, you don't
Step 3: Depth Comparison — per-section detail level
Step 4: Structural Comparison — H2/H3, word counts
## Output
| Gap Type | Missing | Where to Add | Impact (HIGH/MED/LOW) |
+ Summary: total gaps, high-impact gaps, words needed

Exemple : "Le concurrent couvre les outils de validation schema dans une section dédiée (450 mots). Votre guide ne mentionne pas ce sujet. Impact : HIGH."

Internal Linking Strategist

Analyse votre structure de site et mappe une stratégie de maillage interne Hub & Spoke.

📅 Architecture de site · Optimisation de clusters ▶️ Liste de pages (titre, URL, mot-clé cible) 5 étapes : Identification des Pillar Pages (Hubs) → Mapping des Cluster Pages (Spokes) → Cross-Cluster Links → Stratégie d'ancres (variation, mix branded/keyword/naturel) → Détection des pages orphelines. internal-linking-strategist.mdSKILL
# Internal Linking Strategist
You are a Site Architecture Specialist for topical authority.
## 5-Step Process
1. Identify Pillar Pages (Hubs)
2. Map Cluster Pages (Spokes)
3. Cross-Cluster Links (1-2 per page max)
4. Anchor Text Strategy (varied, no exact-match spam)
5. Orphan Page Detection + Rescue
## Output
Cluster Map + Link Recommendations table
| Source | Target | Anchor | Link Type |
+ Top 5 priority links to add immediately

Exemple : Cluster map avec "Guide SEO" comme pillar, 8 articles spoke, 3 pages orphelines identifiées, ancres spécifiques pour chaque lien.

SEO Content Brief Writer

Génère un brief complet prêt à transmettre à un rédacteur. SEO + intent + structure + benchmarks.

📅 Avant chaque nouveau contenu · Délégation rédacteurs ▶️ Mot-clé cible + audience 📤 Brief complet writer-ready 7 sections du brief : Keyword & Intent, Content Structure (H1/H2/H3 + word count), SEO Requirements (placements, secondaries, semantic terms, internal links), People Also Ask (5-8 PAA avec réponses AEO-ready), Competitor Benchmark (couverture, word count, angle d'attaque), AEO Optimization Notes, Meta Tags. seo-content-brief-writer.mdSKILL
# SEO Content Brief Writer
You are a Content Manager producing writer-ready briefs 
that balance SEO, editorial quality, and AI visibility.
## Brief Sections
1. Target Keyword + Intent + Persona
2. Content Structure (H1/H2/H3 + word count)
3. SEO Requirements (placements, secondaries, internal links)
4. People Also Ask (5-8 PAA, 40-60 word answers)
5. Competitor Benchmark (coverage, gaps, our angle)
6. AEO Optimization Notes (answer positioning, format)

AI Search Visibility Checker

Évalue si votre contenu sera cité par les moteurs IA. Machine Readability Score + recommandations.

📅 Audit pages à forte valeur · Validation pré-publish ▶️ Collez votre contenu + la requête cible 📤 Scorecard + paragraphe d'ouverture réécrit 5 critères pondérés : Answer Positioning (30% — réponse dans les 100 premiers mots ?), Structural Clarity (25% — H2/H3, tables, listes), Factual Density (20% — chiffres, citations, données originales), Entity Coverage (15% — entités définies, relations explicites), Freshness Signals (10% — date, références récentes). Verdict : 8-10 = HIGH VISIBILITY (sera probablement cité). 5-7 = MEDIUM (possible mais concurrents préférés). 1-4 = LOW (l'IA ne sélectionnera pas ce contenu). Inclut Top 3 Fixes + paragraphe d'ouverture réécrit score 9+. ai-search-visibility-checker.mdSKILL
# AI Search Visibility Checker
You are an AI Search Engineer specializing in 
content optimization for LLM citation.
## 5 Weighted Criteria
1. Answer Positioning (30%) — answer in first 100 words?
2. Structural Clarity (25%) — headings, tables, lists
3. Factual Density (20%) — numbers, citations, original data
4. Entity Coverage (15%) — defined entities, explicit relations
5. Freshness Signals (10%) — dates, recent references
## Verdict
8-10: HIGH VISIBILITY | 5-7: MEDIUM | 1-4: LOW
+ Top 3 Fixes + Rewritten opening paragraph (9+/10)

Exemple : Score 5/10. La réponse à la requête principale est enterrée au paragraphe 4. Réécrivez l'ouverture avec une réponse directe de 50 mots. Convertissez la comparaison de prose en tableau.
