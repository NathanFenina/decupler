Le garde-fou

C'est la partie dont personne ne parle et qui décide si vous pouvez laisser un agent toucher un site en production.

Deux hooks, avant chaque action

garde-fou.sh bloque les commandes destructrices avant qu'elles s'exécutent. verifier-schema.sh valide le JSON-LD produit avant qu'il parte en ligne. La publication est en brouillon par défaut : rien n'atteint le public sans que vous l'ayez relu.

Les questions qu'on nous pose

C'est gratuit ?

Oui, licence MIT. Vous clonez, vous modifiez, vous utilisez en clientèle sans rien demander à personne.

Il faut savoir coder ?

Non. Vous tapez une commande en français dans Claude Code, les agents font le reste. L'installation est un copier-coller.

Et si je n'ai pas les MCP payants ?

Les 13 MCP sont tous optionnels, avec repli gracieux : sans Ahrefs ni Semrush, les skills qui en dépendent basculent sur ce qui est disponible et vous le disent.

Ça publie tout seul sur mon site ?

Seulement si vous le demandez, et en brouillon par défaut. Un hook garde-fou.sh bloque les actions destructrices avant qu'elles partent.

Quelle différence avec un ChatGPT à qui je demande du SEO ?

Un chatbot vous répond. Ici les agents lisent votre Search Console, crawlent vos pages, interrogent la SERP en direct, corrigent vos fichiers et publient. La réponse n'est pas le livrable — le site corrigé l'est.
