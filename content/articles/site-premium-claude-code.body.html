Créer un site premium avec Claude Code : les Skills et MCP à installer

Claude Code sait coder un site. Ce qui manque pour qu'il soit premium, ce sont des yeux, des références et du goût. Ce guide installe les outils qui les lui donnent : Firecrawl, Playwright, UI UX Pro Max, 21st, Impeccable. Commandes exactes, vérifiées sur la documentation de chaque projet.

Le constat

Pourquoi « crée-moi un site » donne un site générique

Demande un site à une IA sans rien d'autre : tu obtiens la moyenne de tout ce qu'elle a vu. Police Inter, dégradé violet-bleu, trois cartes avec une icône au-dessus du titre. Le code tourne, mais le site ressemble à mille autres. Trois choses manquent :

  • Des références. Elle ne regarde pas les sites de ton secteur qui fonctionnent. → Firecrawl les lit pour elle, identité visuelle comprise.
  • Des yeux. Elle écrit du CSS sans jamais voir le résultat, ni sur mobile ni sur ordinateur. → Playwright ouvre un vrai navigateur et fait des captures.
  • Du goût et un système. Elle ne sait pas quelle palette, quelle typo, quelle structure de page conviennent à un ostéopathe ou à un SaaS. → Les skills UI UX Pro Max et Impeccable, plus les composants de 21st.

Installer Claude Code

Il faut un abonnement Claude payant (Pro, Max…) ou une clé API. Sur macOS et Linux, l'installateur officiel :

terminal
curl -fsSL https://claude.ai/install.sh | bash
# ou, si tu as déjà Node.js :
npm install -g @anthropic-ai/claude-code
# puis, dans le dossier du site :
mkdir mon-site && cd mon-site
claude

Les commandes qui commencent par / (comme /plugin) se tapent dans Claude Code. Les autres se tapent dans le terminal.

Étape 1 · MCP
1

Firecrawl : lire les sites de référence

Firecrawl transforme une page web en texte propre, et son format branding en extrait l'identité : couleurs, polices, typographie, espacements, logo, composants. C'est la matière première du brief : on montre à Claude trois sites qui marchent dans le secteur, il en tire ce qui les rend crédibles.

Le plus simple, le plugin officiel :

dans Claude Code
/plugin install firecrawl@claude-plugins-official

Ou en ligne de commande, avec ta clé (créée sur firecrawl.dev) :

terminal
claude mcp add firecrawl -e FIRECRAWL_API_KEY=fc-TA_CLE -- npx -y firecrawl-mcp
# pour tester sans clé (scrape, search et parse seulement, débit limité) :
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp
💬

À demander : « Avec Firecrawl, récupère le branding de ces trois sites et fais-moi un tableau : couleurs, polices, tailles de titres, espacements, ton des textes. Ce qu'ils ont en commun, ce qui les distingue. »

⚠️

S'inspirer, pas copier : on reprend des principes (contraste, rythme, hiérarchie), jamais un logo, des textes ou une maquette entière. Et chaque page lue consomme des crédits : surveille ton solde.

Étape 2 · MCP
2

Playwright : donner des yeux à Claude

C'est l'outil qui change le plus la qualité. Playwright ouvre un vrai navigateur, charge ta page, la redimensionne, clique, fait des captures. Claude arrête de coder à l'aveugle : il voit le bouton qui déborde sur mobile et le corrige avant que tu le remarques.

terminal
claude mcp add playwright npx @playwright/mcp@latest

Ou /plugin install playwright@claude-plugins-official depuis Claude Code. Par défaut, la fenêtre du navigateur s'affiche : tu vois Claude travailler. L'option --headless la masque.

💬

À demander : « Ouvre le site en local, fais une capture à 390 px, 768 px et 1440 px de large. Liste tout ce qui casse ou qui fait amateur, corrige, puis refais les captures pour me montrer l'avant et l'après. »

Étape 3 · Skill

UI UX Pro Max : le bon design system pour le bon secteur

Ce skill donne à Claude une base de connaissances de design interrogeable. D'après la documentation du projet : 192 catégories de produits, 192 palettes, 74 associations de polices et 34 structures de landing page. À partir de ton secteur, il sort un design system complet : structure de page, style, couleurs, typographies, effets, erreurs à éviter et checklist avant livraison.

dans Claude Code
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

Autre voie, par son installateur (Python 3 requis pour la recherche) :

terminal
npm install -g ui-ux-pro-max-cli
uipro init --ai claude            # dans ce projet
uipro init --ai claude --global   # pour tous tes projets
💬

À demander : « Utilise UI UX Pro Max pour générer le design system d'un cabinet d'ostéopathie haut de gamme à Nice. Je veux la structure de la page d'accueil, la palette, les typos et la liste de ce qu'il faut éviter. »

Étape 4 · MCP
4

21st : des composants prêts au lieu de tout réinventer

21st.dev est une bibliothèque de composants d'interface (sections hero, tableaux de prix, témoignages, menus). Son MCP permet à Claude de chercher un composant, d'en récupérer le code et de l'adapter à ta charte. L'ancien « Magic MCP » s'appelle désormais 21st MCP : les anciennes clés ont été réinitialisées, il faut en créer une nouvelle sur 21st.dev/mcp.

terminal
npx @21st-dev/cli@latest init --client claude

La recherche et la récupération de composants marchent avec la clé gratuite. La génération de composants par l'IA de 21st demande un accès en plus : sans lui, c'est Claude qui adapte le code récupéré, et c'est très bien.

💬

À demander : « Cherche sur 21st une section de témoignages et un tableau de prix à trois colonnes. Prends les deux plus sobres et adapte-les au design system du projet. »

Étape 5 · Skill
5

Impeccable : chasser le « look IA »

Impeccable part du skill frontend-design d'Anthropic et va plus loin : une commande par intention (critique, audit, polish, typographie, mise en page, animation…) et 61 règles qui détectent les tics des sites générés par IA : polices par défaut, dégradés violet-bleu, cartes dans des cartes, texte gris sur fond coloré.

terminal, à la racine du projet
npx impeccable install

Puis, dans Claude Code, une seule fois par projet : /impeccable init. Il pose les questions qui manquent (public, objectif, ton) et écrit un fichier PRODUCT.md que toutes les commandes suivantes relisent.

les commandes les plus utiles
/impeccable craft     # de la forme au code, avec itérations visuelles
/impeccable critique  # revue UX : hiérarchie, clarté
/impeccable audit     # accessibilité, performance, responsive
/impeccable typeset   # polices, hiérarchie, tailles
/impeccable polish    # dernière passe avant livraison

Les autres skills et MCP utiles

Tous disponibles dans la place de marché officielle de plugins Claude Code (/plugin install <nom>@claude-plugins-official) :

  • frontend-design (Anthropic) : pousse Claude vers une direction esthétique affirmée plutôt que le gabarit moyen.
  • context7 : la documentation à jour des bibliothèques (Tailwind, Next.js, Astro…), pour éviter le code écrit pour une version dépassée.
  • chrome-devtools-mcp : traces de performance, requêtes réseau, console. Le complément de Playwright pour la vitesse.
  • figma : si le client arrive avec une maquette, Claude lit les composants et les tokens au lieu de deviner.
  • vercel ou netlify-skills : mettre en ligne et suivre les déploiements sans quitter le terminal.

Pour les visuels, un MCP de génération d'images (chez nous, Gemini) produit les illustrations directement dans le dossier du site.

La méthode

Le déroulé d'un site, de bout en bout

  1. Cadrer/impeccable init : public, offre, ton. Tout part de là.
  2. RegarderFirecrawl sur trois sites de référence du secteur : ce qui les rend crédibles.
  3. Poser le systèmeUI UX Pro Max : structure, palette, typos, interdits.
  4. ConstruireClaude Code, avec les composants de 21st adaptés à la charte.
  5. Voir et corrigerPlaywright : captures mobile et ordinateur, corrections, nouvelles captures.
  6. Finir/impeccable audit puis polish, et mise en ligne.

Le prompt de départ, à adapter :

prompt
Tu construis le site de [ENTREPRISE], [ACTIVITÉ] à [VILLE].
Cible : [CLIENT IDÉAL]. Objectif de la page : [PRISE DE RDV / DEVIS / APPEL].

1. Lis PRODUCT.md. S'il n'existe pas, lance /impeccable init.
2. Avec Firecrawl, récupère le branding de : [URL 1], [URL 2], [URL 3].
   Résume ce qu'ils ont en commun. Ne copie ni texte ni logo.
3. Avec UI UX Pro Max, génère le design system adapté à ce secteur.
4. Construis la page d'accueil. Cherche sur 21st les composants
   dont tu as besoin et adapte-les au design system.
5. Avec Playwright, capture la page à 390, 768 et 1440 px.
   Corrige tout ce qui casse, puis refais les captures.
6. Termine par /impeccable audit et corrige les points bloquants.
Montre-moi les captures finales avant de t'arrêter.

Avant de livrer

La checklist qualité

  • Contraste du texte d'au moins 4,5:1 sur tous les fonds.
  • Focus visible au clavier sur chaque lien et chaque bouton.
  • Aucun débordement horizontal à 375, 768, 1024 et 1440 px.
  • Animations coupées quand le visiteur a activé « réduire les animations ».
  • Pas d'emoji en guise d'icônes : des icônes SVG.
  • Une seule balise H1, des H2 et H3 dans l'ordre, un title et une meta description par page.
  • Images compressées, avec dimensions et texte alternatif.
  • Formulaire testé pour de vrai : le message arrive bien.
💡

Ce que le client paie, ce n'est pas le code, que Claude écrit en quelques minutes. C'est la direction (le cadrage, les références, le système), la qualité vérifiée sur écran, et un site prêt à être trouvé sur Google et cité par les IA.

FAQ

Questions fréquentes

Faut-il savoir coder ?

Non. Il faut savoir ouvrir un terminal, copier des commandes et juger un résultat à l'écran. Claude écrit le code ; ton rôle est celui du directeur artistique : cadrer, choisir, refuser ce qui fait générique.

Combien coûte cette stack ?

Claude Code demande un abonnement Claude (Pro ou Max) ou une clé API. Playwright, UI UX Pro Max et Impeccable sont open source. Firecrawl a une version sans clé limitée et des crédits payants au-delà. 21st fournit une clé gratuite pour chercher et récupérer des composants ; la génération par son IA est en option.

Quelle différence entre un MCP et un skill ?

Un MCP connecte Claude à un outil externe : un navigateur, un site web, une bibliothèque de composants. Un skill est un ensemble d'instructions et de scripts que Claude charge quand la tâche s'y prête : une méthode, des règles, une base de connaissances.

Et pour un site WordPress ?

La méthode est la même pour le design. Claude peut produire un thème léger ou du HTML propre à intégrer, et publier par l'API REST de WordPress. Playwright sert ensuite à vérifier le rendu réel en ligne.

Firecrawl, c'est légal pour s'inspirer d'un concurrent ?

Lire une page publique pour en analyser le style, oui. Reprendre ses textes, son logo ou sa maquette, non. Le guide s'en sert pour dégager des principes, pas pour cloner.
